# 영상편집 작업 폴더

| 폴더 | 넣는 것 |
|---|---|
| 원본영상 | 비즈에서 만든 목소리 MP4, 사이트 화면 녹화 원본 |
| 레퍼런스 | 참고하고 싶은 영상 링크(links.md)와 대표가 보낸 캡처 |
| 완성본 | 인스타판(reel-*.mp4)·네이버 클립판(clip-*.mp4)·표지(thumb.jpg) |

도구: 장면 = HTML + Playwright(Remotion·HyperFrames와 같은 방식), 컷·합치기·내보내기 = ffmpeg, 대사 타이밍 = tools/voice_sync.py(무음 구간으로 문장 나눔).
